CSS e suas Formas de Aplicar

Ao aplicar o CSS em uma página, ele pode ser aplicado de três formas, elas são: In line, internal e external.

In line:

O CSS In Line é aplicado dentro da tag no projeto HTML. Ela é a tecnica mais básica, mas a mais poluída e complicada de aplicar manutenção depois.
Aqui temos alguns exemplos de CSS In line

Internal:


Esse método permite alterar o estilo das tags dentro da head, podendo usar elas configuradas na página toda. Dessa forma, evita repetição durante o código e facilita a manutenção.
Aqui temos um exemplo de página usando o CSS Internal

External

Essa é a abordagem mais avançada de CSS, onde o código CSS é escrito em um arquivo a parte (terminado em ".css"). Assim, a manutenção se torna mais fácil e o estilo das tags podem ser usados em diversas páginas HTML.
Aqui temos um exemplo de página usando o CSS External
